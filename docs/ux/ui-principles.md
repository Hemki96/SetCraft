# UI Principles

## Grundprinzipien

### 1. Fachliche Klarheit vor visueller Spielerei
Die Oberfläche soll die Trainingslogik verständlich machen, nicht dekorativ überladen.

### 2. Sichtbarkeit von Status
Der Nutzer muss jederzeit erkennen:
- was historisch ist
- was generiert ist
- was geprüft wurde
- was freigegeben ist
- wo Warnungen oder Unsicherheiten vorliegen

### 3. Struktur vor Freitext
Die UI soll strukturierte Felder sichtbar priorisieren, ohne den Bezug zum Rohtext zu verlieren.

### 4. Reviewbarkeit ist Kernfunktion
Die Oberfläche ist nicht primär ein hübscher Export-Viewer, sondern ein Arbeitswerkzeug für Kontrolle und Korrektur.
