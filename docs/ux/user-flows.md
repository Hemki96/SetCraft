# User Flows

## Flow 1 – Historischen Trainingsplan importieren
1. Trainer öffnet Upload-Seite
2. Trainer wählt Datei oder fügt Text ein
3. Upload wird bestätigt
4. System zeigt Verarbeitungsstatus
5. Trainer kann zur Quellenliste oder zum Detail wechseln

## Flow 2 – Extrahierten Datensatz prüfen
1. Trainer öffnet Quelle oder zugehörige Session
2. System zeigt Session-Übersicht
3. Trainer sieht Blocks und Sets
4. Trainer vergleicht Normalform mit Rohtext
5. Trainer korrigiert Felder
6. Trainer speichert Änderungen
7. Trainer markiert Datensatz als reviewed

## Flow 3 – Historische Inhalte suchen
1. Trainer öffnet Suche
2. Trainer setzt Filter oder Suchbegriff
3. System zeigt Trefferliste
4. Trainer öffnet Detailansicht
5. Trainer übernimmt Treffer als Referenz
