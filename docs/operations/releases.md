# Release-Strategie

## Grundprinzipien
- kleine, inkrementelle Releases
- dokumentierte Änderungen
- keine impliziten Produktionsfreigaben
- fachlich sensible Features nur mit bewusster Freigabe

## Versionierung
Empfohlen:
- SemVer-orientiert
- Start mit `0.x.y` im MVP

## Release-Voraussetzungen
- relevante Tests grün
- zentrale Dokumentation aktuell
- bekannte Einschränkungen dokumentiert
- Smoke-Test durchgeführt
- Rollback- oder Restore-Weg bekannt
