# ADR 0001 – Backend-Framework FastAPI

## Status
Accepted

## Kontext
Die Plattform benötigt ein API-zentriertes Backend mit guter Typisierung, klaren Request-/Response-Verträgen und moderner Python-Integration.

## Entscheidung
Als Backend-Framework wird **FastAPI** verwendet.

## Begründung
- API-zentrierte Architektur
- direkte Pydantic-Integration
- automatische OpenAPI-Dokumentation
- gute Testbarkeit
