# Definition of Done

## Allgemeine Definition of Done

Eine Änderung ist nur dann done, wenn:
- der Zweck der Änderung klar ist
- die Änderung den dokumentierten Anforderungen entspricht
- der Scope eingehalten wurde
- relevante Tests vorhanden und erfolgreich sind
- Linting und Typprüfung erfolgreich sind
- betroffene Dokumentation aktualisiert wurde
- neue Annahmen explizit gemacht wurden
- keine stillen Architektur- oder Fachbrüche entstanden sind

## Merge-Checkliste

- [ ] Anforderungen verstanden
- [ ] Scope klar eingehalten
- [ ] Code konsistent
- [ ] Tests grün
- [ ] Lint grün
- [ ] Typecheck grün
- [ ] Doku aktualisiert
- [ ] keine stillen Architekturbrüche
- [ ] relevante Risiken benannt
