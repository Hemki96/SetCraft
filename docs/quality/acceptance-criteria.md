# Acceptance Criteria

## MVP-weite Akzeptanzkriterien

### AC-MVP-001 – Historische Pläne sind importierbar
Ein Trainer kann unterstützte Quelldateien oder Freitext in das System einbringen.

### AC-MVP-002 – Historische Pläne sind strukturierbar
Das System kann aus unstrukturierten Quellen strukturierte Trainingsobjekte erzeugen.

### AC-MVP-003 – Manuelle Korrektur ist möglich
Ein Trainer kann automatisch extrahierte Inhalte prüfen und anpassen.

### AC-MVP-004 – Historische Inhalte sind sinnvoll suchbar
Ein Trainer kann relevante historische Inhalte finden.

### AC-MVP-005 – Neue Sets und Einheiten sind generierbar
Das System kann neue Inhalte auf Basis von Regeln und historischen Referenzen erzeugen.

### AC-MVP-006 – Generierte Inhalte werden validiert
Generierte Inhalte werden vor Nutzung fachlich geprüft.

### AC-MVP-007 – Freigabe ist kontrolliert
Trainer können Inhalte freigeben oder ablehnen.

### AC-MVP-008 – Ergebnisse sind exportierbar
Freigegebene Inhalte können aus dem System heraus genutzt werden.
