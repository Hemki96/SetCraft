# Core Use Cases

## Übersicht der Kern-Use-Cases

1. Historischen Trainingsplan importieren
2. Extrahierten Trainingsplan prüfen und korrigieren
3. Historische Inhalte suchen und wiederverwenden
4. Neues Set erzeugen
5. Neue Einheit erzeugen
6. Wochenplan erzeugen
7. Freigeben und exportieren

## Use Case 1 – Historischen Trainingsplan importieren
### Ziel
Ein Trainer lädt einen alten Trainingsplan hoch, damit dieser strukturiert ins System übernommen werden kann.

## Use Case 2 – Extrahierten Trainingsplan prüfen und korrigieren
### Ziel
Ein Trainer prüft die automatisch strukturierte Trainingseinheit und korrigiert fehlerhafte Zuordnungen.

## Use Case 3 – Historische Inhalte suchen und wiederverwenden
### Ziel
Ein Trainer sucht nach passenden alten Sets, Blöcken oder Einheiten als Referenz für neue Planung.

## Use Case 4 – Neues Set erzeugen
### Ziel
Ein Trainer möchte für einen bestimmten Trainingszweck ein neues Set vorgeschlagen bekommen.

## Use Case 5 – Neue Einheit erzeugen
### Ziel
Ein Trainer möchte eine komplette Trainingseinheit erzeugen lassen.

## Use Case 6 – Wochenplan erzeugen
### Ziel
Ein Trainer möchte mehrere Einheiten im Wochenkontext erzeugen lassen.

## Use Case 7 – Freigeben und exportieren
### Ziel
Ein Trainer möchte einen geprüften Inhalt freigeben und in ein nutzbares Format exportieren.
